PORTOFOLIO ALFINO SYAHPUTRA

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder alfino_portfolio.
3. Klik dua kali index.html atau buka dengan browser.
4. Untuk mengedit kode, buka index.html dan style.css di VS Code.

Catatan:
- Avatar saat ini adalah ilustrasi SVG yang dibuat langsung di HTML, jadi tidak perlu file gambar terpisah.
- Ganti https://github.com/ dengan URL profil GitHub pribadi sebelum dipublikasikan.
- Tautan email mailto: belum berisi alamat email. Isi jika ingin menampilkannya.
- Kartu proyek adalah contoh ide/konsep. Sesuaikan status dan deskripsi dengan proyek yang benar-benar dikerjakan.
- Skill teknologi diberi label sedang dipelajari agar tidak mengklaim penguasaan yang belum tentu sesuai.
